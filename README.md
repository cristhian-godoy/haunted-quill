# Haunted Quill ✒️

**Don't stop typing. The ghosts are waiting.**

Haunted Quill is a high-stakes, distraction-free writing tool designed to keep you focused. If you pause for too long, the "ghosts" will begin to eat your words, one by one. The longer you wait, the faster they consume your progress.

## ✨ Features

- **Ghostly Deletion:** A unique motivation mechanic that deletes words if you stay idle.
- **Difficulty Presets:**
  - **Zen:** Long grace period, slow deletion.
  - **Forgiving:** A gentle nudge to keep moving.
  - **Normal:** The standard haunted experience.
  - **Brutal:** For the most disciplined scribes.
- **Backup Archive:** Automatically takes a snapshot of your work the moment before the ghosts start eating, so you never lose everything.
- **Panic Button:** Quickly restore your latest snapshot if the haunting gets out of hand.
- **Atmospheric Visuals & Sound:** Spooky animations and adaptive audio feedback that intensifies as the ghosts speed up.

## 🛠️ How to Use

1. Open `index.html` in any modern web browser.
2. Select your difficulty level.
3. Start typing.
4. **Whatever you do, don't stop.**
